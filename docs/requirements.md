# 员工信息管理系统 · 需求文档

## 1. 项目背景与目标
一句话：为中小企业提供员工与部门信息管理 + 登录认证的后端服务，
解决"员工信息分散在 Excel、部门人员统计困难"的问题。

## 2. 用户角色
| 角色 | 说明 | 主要权限 |
|---|---|---|
| 管理员 | 人事/主管 | 部门与员工的增删改查、查看操作日志 |
| 普通用户 | 员工本人 | 登录、查看/修改自己的信息 |

## 3. 功能需求
| 模块 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| 部门管理 | 列表/新增/修改/删除 | 部门名称唯一；有员工时不许删（外键约束） | P0 |
| 员工管理 | 列表/新增/修改/删除 | 支持按姓名、部门、入职时间**多条件查询** + 分页 | P0 |
| 员工管理 | 头像上传 | 上传后保存路径 | P1 |
| 登录认证 | 登录/退出/令牌校验 | 密码加密存储；未登录不能访问接口 | P0 |
| 操作日志 | 自动记录 | 谁在什么时间做了什么（AOP 实现） | P1 |

## 4. 非功能需求
- 接口响应 < 1s（常规查询）；密码不能明文存；所有入参做校验；关键操作留日志

## 5. 技术选型
后端：Java 17 + SpringBoot 3 + MyBatis + MySQL 8
前端：Vue3 + Element Plus（极简，只做登录页 + 员工表格页）
工具：Git / Maven / Apifox 或 Postman / IDEA
